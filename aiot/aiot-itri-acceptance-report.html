交付項目 (1) · 場域驗證 5 項

AI 感知動態事件驅動決策支援系統場域驗證測試個案

涵蓋「空調製冷、外氣自然冷源、變頻通風、電網需量控制、動態能源基線」五大實證情境

查核狀態：5 項全數通過
TC-01

熱負荷預測與 VRV 壓縮機預冷降載控制

MPC 負載預測 ＋ 行事曆 MCP
驗證場域空間 12F 研發處大會議室 (BLK_1202)

外牆西曬、具備高熱慣性係數

AI 感知與演算法 MPC 建築熱負荷預測 API

氣象局預報 API ＋ Google Calendar MCP

動態事件驅動 event.schedule.meeting_approaching

開會前 30 分鐘自動觸發協商

驗收指標 (KPI) 尖峰電費降 18%

散會前 15 分鐘利用熱慣性提前斷冷

實證閉環流程：行事曆 MCP 偵測到 14:00 有 30 人會議，氣象 API 傳回室外高溫 35°C；Task Agent 避開 13:00~15:00 尖峰高電價，於 12:40 離峰尾聲提前平穩預冷；開會結束前 15 分鐘自動切斷冷媒供給利用建築餘溫保溫。主管於 Generative UI 一鍵核准執行。
TC-02

全熱交換器 (ERV) 智慧焓值旁通與自然冷源利用

空氣焓值運算 ＋ 自然冷源
驗證場域空間 8F 開放式辦公區 (BLK_08F)

共軛風道：同區 ERV 與 VRV 聯動

AI 感知與演算法 多變量決策樹空氣焓值 API

室內外溫濕度計即時計算 Enthalpy

動態事件驅動 event.climate.free_cooling_eligible

室外焓值低於室內且 RH < 70%

驗收指標 (KPI) 機械製冷能耗降 28%

結露次數 = 0，自動防潮保護

實證閉環流程：早秋早晨室外氣溫 22°C 且濕度涼爽，系統算得室外空氣焓值低於室內；CEP 拋出自然冷源事件，Task Agent 調度 BOS Gateway 將 ERV 切換為旁通模式（Bypass Mode），直接引入自然冷源，同步將 VRV 壓縮機降頻至最低，實現大幅節能。
TC-03

基於 CO₂ 累積速率斜率之 ERV 變頻需量通氣 (DCV)

卡爾曼濾波 ＋ 模糊控制
驗證場域空間 10F 階梯演講廳 (BLK_10F)

高密度流動人潮、空間容量 120 人

AI 感知與演算法 Kalman Filter ＋ Fuzzy Logic API

濾除感測噪聲、計算上升斜率

動態事件驅動 event.iaq.co2_rapid_rise

斜率 > 25 ppm/min 立即觸發

驗收指標 (KPI) 風機用電降低 22%

CO₂ 全程 < 800 ppm，超標時間 0

實證閉環流程：大批人員入場時，不等 CO₂ 破千才全速補救，卡爾曼濾波器偵測到上升斜率異常陡峭，提前 15 分鐘平滑拉升 ERV 變頻風機至 80% 開度；散會後斜率轉負即降速，兼顧空氣品質與風機節能。
TC-04

結合時間電價與需量控制 (DR) 輪換卸載

Deep RL (A3C) ＋ 紅綠分區
驗證場域空間 全棟垂直 Block 矩陣 (全場域)

🔴核心保護區 vs 🟢彈性緩衝區

AI 感知與演算法 A3C 強化學習雙目標尋優 API

台電 TOU 電價 API ＋ 契約容量門檻

動態事件驅動 event.energy.dr_peak_warning

15分鐘需量預測達 92% 觸發

驗收指標 (KPI) 超約罰款次數 = 0

削峰率 12%，滿意度維持 92%

實證閉環流程：夏日高溫即將突破 500 kW 契約容量上限時，系統嚴格保護機房/高管室（恆溫禁卸載），對茶水間、走廊、大廳等彈性空間執行每 10 分鐘接力調升 +1°C 輪換卸載，成功消除尖峰罰款且員工無體感不適。
TC-05

ISO 50001 動態能源基線與異常偏離診斷

XGBoost ＋ CUSUM 統計診斷
驗證場域空間 B1 冰機水路與 6F 空調箱 (BLK_B1)

水泵電表、冰水流量計、閥門反饋

AI 感知與演算法 XGBoost 歸一化基線 ＋ CUSUM API

排除氣溫、人數、營運天數干擾

動態事件驅動 event.diagnostic.baseline_anomaly

累積偏離突破 3σ 閾值觸發

驗收指標 (KPI) 故障提前 48 小時檢出

動態基線擬合度 R² ≥ 0.94

實證閉環流程：XGBoost 模型排除天候與人數干擾後建立精準動態基線。當 6F 空調箱二通閥發生微幅內漏時，CUSUM 統計量突破臨界值，Task Agent 沿空間 Block 拓撲反查成功定位故障設備，向主管推播【危機分診卡】，防範未然。
