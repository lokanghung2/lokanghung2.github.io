3. 明確定義兩大人類角色規範 (Roles & Responsibilities)

架構上徹底區隔「業務經營」與「技術架構」，讓人與 AI 和諧共生、各司其職

角色 1 • 業務決策 Business Manager

👤 業務管理者 / 營運主管

適合人選：總務主管、廠務處長、ESG 永續經理、大樓資產營運主管。

核心職責清單：

  • 1. 動口下達戰略目標：使用白話輸入經營策略（如預冷、壓低尖峰、防超約）。
  • 2. 補齊業務情境資訊：回應 AI 主動提出的業務問題（如確認開會人數）。
  • 3. 審核放行控制策略：檢視效益預測報告（省電率、舒適度），按下一鍵核准。
  • 4. 固化長期自動化排程：將成效良好的調度流程保存為長期功能。
🔒 操作邊界：純業務視角，零技術門檻，完全不需接觸任何代碼與通訊協定。
角色 2 • 知識架構 Building Knowledge Architect

👤 建築語意架構師

適合人選：弱電/BMS 系統整合工程師 (SI)、BIM 建模師、建築設備工程師。

核心職責清單：

  • 1. 建立空間語意圖譜：依 CAD/BIM 圖面定義空間層級、用途與西曬/散熱特性。
  • 2. 為 IoT API 標註脈絡：將 Gateway 冰冷代碼（DEV_001）綁定到實體會議室。
  • 3. 回應 AI 主動探詢：當 AI 發現設備缺乏空間歸屬時，及時標註補充。
  • 4. 賦予設備空間靈魂：使 AI 真正具備空間感知，從而能自主組裝流程。
🔒 操作邊界：專注空間與拓撲正確性，不干涉日常經營決策與演算法內部運算。
比較維度 角色 1：業務管理者 / 營運主管 角色 2：建築語意架構師
關注核心 節能效益、舒適度、電費成本、營運安全 空間拓撲、設備對應、西曬屬性、語意完整性
系統輸入 自然語言目標、會議人數、一鍵核准指令 CAD/BIM 空間定義、API 空間標籤、拓撲關係
技術門檻 完全無技術門檻（使用白話對話介面） 需具備建築空間識圖與弱電設備點位理解能力
參與時機 日常營運、隨時下達目標、排程審核 系統初期建置、空間變更、回應 AI 語意探詢

4. 四大核心層次運作機制

從意圖到執行的模組化職責與分工

1

管理者意圖層

告別複雜監控畫面。管理者僅需表達高階意圖（如：「降低尖峰避免超約」或「重要會議前預冷」），AI 自動處理其餘細節。

2

AI Orchestrator 大腦

系統運作中樞。負責意圖拆解、主動缺失探詢（發現缺少感測器或空間語意時主動開口問人），並自動組裝流程鏈。

3

語意圖譜 + 算法庫

雙支柱支撐：語意圖譜解決「去哪裡控制、控制誰」；演算法微服務 API 解決「設定多少數值才科學、最節能」。

4

現有 IoT Gateway API

現場既有資產。提供標準讀取（溫濕度、電表）與控制（開關、溫度、風閥開度）API，穩定執行 AI 下發的物理控制指令。

6. 首批演算法模型庫清單（Algorithm as API 規格）

將高深數理、熱力學與機器學習封裝為標準 API 微服務，供 AI 大腦自由調用

API 1 • MPC 負載預測

VRV 壓縮機預冷降載控制

結合天氣預報與空間熱慣性，提前精算預冷啟動時間，會議結束前 15 分鐘提前斷冷利用餘溫，平抑尖峰用電衝擊。

API 2 • Free Cooling

ERV 智慧空氣焓值旁通利用

即時計算室內外空氣焓值（Enthalpy），秋涼或早晚室外乾爽時自動開啟 ERV 旁通模式引進自然冷源，空調壓縮機降頻或停機。

API 3 • 卡爾曼濾波 + 模糊控制

基於 CO₂ 累積速率之變頻通氣 (DCV)

分析 CO₂ 濃度上升/下降斜率，克服感測器反應延遲，精準預估人流變動，動態調整 ERV 變頻風量，節能又確保好空氣。

API 4 • Deep RL (A3C)

結合時間電價之尖峰負載轉移與輪卸

尖峰時段或即將超約時，自動對非核心區域（走廊、茶水間）VRV 進行 1°C 微幅上調輪換卸載，避開超約罰款與高尖峰電費。

API 5 • C-TimeGAN 數位雙生

虛擬試車與自適應調優模擬

控制指令下發前，先在數位鏡像中進行無風險虛擬試車，模擬溫度震盪與需量影響，能使實體大樓溫度震盪最高降低 52.1%。

API 6 • XGBoost + CUSUM

ISO 50001 動態能源基線與異常告警

排除氣溫與人流干擾建立動態基線，即時計算能耗累積偏差。當空調冷媒外洩或機械老化時，第一時間精準定位故障點。

7. 結論：架構的核心優勢

保護既有投資

不推翻既有的 IoT Gateway 與硬體線路，站在現有設備 API 基礎上升維。

免除寫死功能

不再需要工程師逐一開發特定場景功能，只要語意標註完整，AI 大腦自主組裝流程。

人機職責純粹

管理者管目標與核准，架構師管語意圖譜，算法庫管精算，AI 大腦管全域調度。
